This folder contains additional data and code used to produce Figure 1 in the manuscript (introduction)

  - Panel A (life cycle) does not use any code.
  - Panel B is generated based on the data in the `COI_divergence/` folder with an R script `Fig1B_plot_distances.R`.
  - Panels C and D are taken from [Drozdova et al., 2022](https://www.mdpi.com/1422-0067/23/18/10858), so please see [the associated GitHub repository](https://github.com/drozdovapb/EveWxS_git/) for reproducible code. However, reproducible code to draw the map for 1D is provided in the script `Fig1D_map_ggmap.R`, as the functions have changed.
